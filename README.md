# NotesScanner

Нативное Android-приложение для сканирования и организации заметок. Позволяет быстро захватывать изображения через камеру, обрезать и сохранять их как заметки.

## Технологии
- Kotlin
- Jetpack Compose
- CameraX
- MVVM Architecture
- Room (локальное хранилище)
- Retrofit (сетевое взаимодействие)
- Coroutines + Flow

## Основные возможности
- Захват изображений через камеру
- Обрезка и предпросмотр фото
- Сохранение заметок в локальную БД
- Синхронизация с сервером (REST API)
- Адаптивный интерфейс
- Навигация между экранами
